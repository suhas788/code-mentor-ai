**Code Mentor AI**

An interactive code explanation assistant built with React + TypeScript, Vite and Supabase Functions. This project provides a minimal UI for pasting code and receiving explanations generated by a serverless function (see `supabase/functions/explain-code`).

**Features**
- **Interactive UI:** Simple code input and explanation output components.
- **Serverless explain function:** Uses Supabase Functions to run the backend explanation logic.
- **TypeScript + React:** Built with Vite, Tailwind CSS and modular UI components.

**Tech Stack**
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Supabase Functions (serverless) for code explanation
- **Dev tooling:** pnpm/npm, Vitest configured for tests

**Quick Start**
- **Prerequisites:** Node.js (18+ recommended), npm or pnpm, a Supabase project if you want the function to run against real credentials.
- Install dependencies:

```bash
npm install
# or
pnpm install
```

- Run the dev server:

```bash
npm run dev
# or
pnpm dev
```

- Build for production:

```bash
npm run build
```

**Environment**
- Create an `.env` / `.env.local` file with these variables when using Supabase:

```
VITE_SUPABASE_URL=<your-supabase-url>
VITE_SUPABASE_ANON_KEY=<your-supabase-anon-key>
```

**Important files**
- `src/components/CodeInput.tsx` — input UI for code snippets
- `src/components/ExplanationOutput.tsx` — displays explanation results
- `supabase/functions/explain-code/index.ts` — serverless function handling explanations
- `src/lib/utils.ts` — shared utilities

**Testing**
- Run unit tests configured with Vitest:

```bash
npm test
```

**Development notes**
- The frontend is intentionally componentized under `src/components` and `src/components/ui` for reusability and easy styling with Tailwind.
- The `supabase/functions/explain-code` function illustrates how the app sends code to a backend endpoint for processing. Update the function or the client environment variables to point to your Supabase project.
